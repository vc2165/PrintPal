Printer setup

How it works

PrintPal sends everything through Android's own printing. Your printer appears on the print screen once a print service on this phone can see it.

  1. Connect the phone to the same Wi-Fi as the printer, and switch the printer on.
  2. Make sure a print service is turned on in Print settings (below).
  3. Print anything. On the print screen, tap the printer name at the top and pick yours.

Print services on this phone

Printer not showing up?

Most Wi-Fi printers work with Mopria Print Service. If yours still doesn't appear, install your printer brand's plugin:

Still missing? Print the printer's network page and check it's on the same Wi-Fi. Many printers also have a Wi-Fi Direct mode that the print services can find.
