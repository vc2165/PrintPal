# PrintPal

Personal Android printing app: photos (collages, passport/stamp sheets), documents (PDF, Word .docx, Excel/CSV, text, HTML), web pages and scan-to-PDF. Printing goes through Android's print system, so any Wi-Fi printer visible to Mopria or the brand's print service works. Also appears in **Share → PrintPal** from other apps.

Every push to `main` builds a signed APK (GitHub Actions) and publishes it under **Releases**. Needs the `KEYSTORE_BASE64` repo secret.
